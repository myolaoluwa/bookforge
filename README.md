# Folio Studio

A static, responsive agency concept inspired by the supplied animated city film. Serve `dist` with a static web server. No build or dependency installation is required.

The reference video has been compressed into an 800 × 1200 muted looping film, with a separate looping soundtrack enabled through the sound control. The sound continues independently when the video is paused. Reduced motion pauses the video by default.

Project briefs are generated locally as text downloads. No form submission endpoint is configured. Replace this workflow with the agency's real contact or lead endpoint before treating it as a live inquiry channel.

The layout study is illustrative; no testimonials, client projects, or performance claims are invented. Manrope is loaded from Google Fonts.
