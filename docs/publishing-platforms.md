# Publishing platform strip

Added immediately below the homepage hero. Amazon Kindle, Barnes & Noble, Lulu, IngramSpark, Rakuten Kobo and Apple Books represent print and ebook publishing paths. This is file-preparation support, not an integration or partner endorsement; file requirements remain part of the project brief.

Warm paper background, Cormorant heading and Manrope supporting copy use existing design tokens. Logos retain their native source colours with no grayscale, brightness or opacity filters. A single horizontally aligned row loops at a steady pace over 120 seconds, including on mobile; the longer duration preserves the slow speed of the expanded list. Two equal groups make the seam continuous. Decorative repetitions are hidden from assistive technology; the focusable region names all six platforms once. Hover on mouse devices and keyboard focus pause the strip. Reduced motion shows one static, wrapping set. Duplicate items are marked explicitly so adding another platform does not break that static set.
